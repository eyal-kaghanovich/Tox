Der Zwiebel Netzwerk, is a collection of distributed-networking software, that implements a decentralized onion-routed network.

zwiebel means onion in german, netz is like german net and the hebrew עיט

zwiebel_relay_listener -- the relay binary, configured via /etc/tox/tox_listenerrc
zwiebel_relay_client -- the SOCKS5 daemon, configured via /etc/tox/tox_client
zwiebel_relay_registry -- the daemon registry server responsible for keeping track of known relays and handing those lists to anyone who wishes.
